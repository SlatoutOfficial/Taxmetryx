# Homepage reference assets

The `*-reference.webp` assets were generated for this site using the section mockups in the supplied Taxmetryx.pdf as visual references. Their text and interface elements are implemented separately in the homepage components.

- `hero-reference.webp`: Dubai terrace and skyline, PDF page 2.
- `values-reference.webp`: five balanced geometric stones, PDF page 17.
- `insights-reference.webp`: red-edged concrete architecture, PDF page 19.
- `contact-reference.webp`: architectural gateway and skyline, PDF page 22.

Original image assets remain available for the other site pages.

The geographic paths in `src/data/world-map.json` were projected from the world-atlas countries-110m dataset: https://cdn.jsdelivr.net/npm/world-atlas@2/countries-110m.json. They are bundled locally; the map does not fetch external data at runtime.

The local Inter and DM Serif Display fonts and their OFL licenses are in `src/app/fonts`.
